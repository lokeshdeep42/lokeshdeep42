## 🧠 About Me

I build GenAI systems end to end — the agent graph, the retrieval layer underneath it, and the backend that has to keep serving traffic when the model misbehaves.

Most of my work sits at the intersection of **multi-agent orchestration** and **retrieval you can actually trust**. LLM applications fail quietly: they produce confident, well-formatted answers nobody can trace back to a source. The plumbing that closes that gap — deterministic verification, eval harnesses that gate CI, hybrid retrieval you can debug — is what I care about most.

Day to day I work in .NET and Python at CGS India, and take on full-stack AI builds alongside it. Right now I'm building **Winaperk**, a QR-to-game customer-retention SaaS for cafés and bars.

### [EarningsLens](https://github.com/lokeshdeep42/EarningsLens) · [Live demo →](https://earnings-lens-2kad.vercel.app/)

A multimodal financial RAG system that refuses to hallucinate numbers. Every numeric claim in a drafted answer is extracted and checked against retrieved source text by a **deterministic Python verifier — not another LLM** — with a bounded revise loop when a figure can't be supported.

`LangGraph` `FastAPI` `pgvector` `React` — 173 offline tests · 29-question gold set · 2 CI-gated metrics

---

### [Pipeline-Builder](https://github.com/lokeshdeep42/Pipeline-Builder)

A node-based visual editor for composing LLM pipelines. Drag-and-drop DAG construction with dynamic handles generated from `{{variable}}` patterns, backed by a FastAPI service that validates graph structure before execution.

`React` `ReactFlow` `Zustand` `FastAPI`
